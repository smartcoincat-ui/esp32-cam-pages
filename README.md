# ESP32-CAM Viewer (GitHub Pages)

Статическая страница для просмотра ESP32-CAM.

## Что важно

GitHub Pages **не может напрямую открыть локальный IP** (`192.168.x.x`) для внешнего интернета.
Чтобы смотреть камеру удалённо, нужен публичный прокси/туннель к вашей камере (например Cloudflare Tunnel/Tailscale Funnel/Nginx reverse proxy).

После этого в поле на странице укажите публичный URL камеры и пользуйтесь:
- поток: `:81/stream`
- снимок: `/capture`
